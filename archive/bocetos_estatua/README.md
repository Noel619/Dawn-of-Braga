# Las láminas con la estatua

Las dos primeras láminas (`tools/bocetos/`), tal como se dibujaron cuando el ídolo
de la fuente era la estatua: «I · El arzobispo, consumido» y «II · Los que la
encontraron primero». Cuando el ídolo pasó a ser el monolito (octubre de 2026)
se volvieron a dibujar con él (`arte/bocetos/`); éstas se guardan aquí. El código
que las dibujaba está en la historia del repositorio (la versión de
`tools/bocetos/arzobispo.js` y `tools/bocetos/romanos.js` del commit e7376da).
