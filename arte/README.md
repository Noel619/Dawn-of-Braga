# Arte

El arte del juego: las láminas dibujadas (`bocetos/`, que se dibujan con
`tools/bocetos/`).

Aquí no se borra nada. Cuando una lámina se vuelve a dibujar, la versión de antes
no se tira ni sale de esta carpeta: se guarda al lado, en una subcarpeta con su
explicación (como `bocetos/estatua/`, las láminas de cuando el ídolo era la estatua).
